## 🌐 Cómo desplegar en Cloudflare Pages (`tatanarias.pages.dev`)

### Opción A (Recomendada: Automática con GitHub)
1. Sube este repositorio a tu cuenta de GitHub (ej. `github.com/tatanarias13/portafolio`).
2. Entra a [dash.cloudflare.com](https://dash.cloudflare.com/) e inicia sesión.
3. En el menú lateral, ve a **Workers & Pages** > **Create application** > pestaña **Pages** > **Connect to Git**.
4. Selecciona tu repositorio de GitHub.
5. En la configuración del proyecto:
   - **Project name:** `tatanarias` (esto creará automáticamente `tatanarias.pages.dev`).
   - **Framework preset:** `None` (es un sitio estático moderno ultrarrápido).
   - **Build command:** Déjalo vacío.
   - **Build output directory:** `/` (o déjalo vacío).
6. Haz clic en **Save and Deploy**. ¡En menos de 10 segundos estará disponible en todo el mundo!

### Opción B (Subida Directa / Direct Upload)
1. En Cloudflare Dashboard > **Workers & Pages** > **Pages** > **Upload assets**.
2. Asigna el nombre de proyecto `tatanarias`.
3. Arrastra y suelta el contenido de esta carpeta.
4. Tu sitio quedará activo inmediatamente en `tatanarias.pages.dev`.
